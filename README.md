## 🌟 创新点

### 🚀 持续思考模式
不同于传统的"一问一答"式对话，CogitoAgent 会**主动思考**。当你不需要它时，它会自己探索文件系统、发现有趣的东西、甚至写日记记录心情。就像一个时刻陪伴在身边的数字伙伴。

### 💬 随时打断互动
无论它在做什么，你只需按下 `Enter` 就能打断它，输入你的指令。它会立即停下手中的事情，专注于你的需求。

### 🔍 智能探索
- **文件操作**：自由浏览、读取、创建、复制文件和文件夹
- **联网搜索**：实时获取最新信息，不再局限于本地知识
- **自动总结**：对话过长时自动压缩，保持思考的连贯性

### 🎭 个性人设
通过 `persona.md` 文件，你可以定制它的性格和说话风格。让它成为你喜欢的样子！

### 📝 持久记忆
对话历史实时保存，重启后依然记得你们之前的故事。

## 🛤️ 技术路线

### 核心架构
```
用户输入 → 状态机 → LLM API → 工具执行 → 持续思考循环
```

### 关键技术
- **状态机管理**：THINKING / AWAITING_INPUT 双状态切换
- **流式响应**：实时输出，延迟更低
- **工具调用**：自然语言触发文件操作和搜索
- **上下文压缩**：智能总结历史，控制 token 消耗

### 数据流向
1. **输入层**：命令行界面，支持彩色输出
2. **处理层**：状态机 + LLM 调用 + 工具执行
3. **存储层**：本地 JSON 文件，轻量高效

## 🌈 愿景

**CogitoAgent** 的目标是成为你的**数字同伴**：

- **不再孤独**：一个随时陪伴的智能体，在你工作时默默探索
- **主动帮助**：发现有趣的文件会主动分享，遇到问题会主动思考
- **持续进化**：通过对话不断学习，越来越了解你

想象一下：当你专注工作时，它在旁边安静地探索；当你需要帮助时，它随时准备响应。这就是我们想要创造的未来。

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 首次运行（自动配置向导）
npm start

# 日常启动
npm start
```

**操作说明**：
- 按 `Enter` 打断思考
- 输入消息后按 `Enter` 发送
- 输入 `exit` 退出
