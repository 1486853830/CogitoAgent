# 🧠 CogitoAgent

**本地文件智能探索助手** 

![main](show/main.png)

---

## 产品简介

CogitoAgent 是一款运行于本地的 AI 智能体，专注于文件探索与知识管理。它直接在你的工作目录下运行，无需上传文件至任何第三方服务器，在保障数据隐私安全的同时，为你提供持续运转的智能文件助理服务。

**核心定位：让沉睡的本地文件，变成可对话的知识资产。**

---

## 核心能力

### 🔒 隐私优先的本地架构
- 所有文件操作均在本地完成，数据不出本机
- 对话历史以 JSON 格式存储于本地，不经过云端
- 支持自定义工作区路径，精确控制 AI 的活动范围

### 🧠 持续思考与自主探索
- 启动后持续运转，自动触发一次思考循环
- 主动探索文件系统结构，发现并记录有价值的内容
- 支持上下文压缩机制，150 轮对话后自动总结历史，保持推理连贯性

### 💬 实时打断与精准响应
- ENTER 键随时中断当前思考，立即响应用户指令
- 支持 `[WAIT]` 标签，AI 可主动暂停等待用户回复
- 状态机（THINKING / AWAITING_INPUT）确保人机交互流畅无竞态

### 🎨 灵活的人格定制
- 通过 `persona.md` 自定义 AI 的性格与语言风格
- 首次运行时配置工作区路径，开箱即用
- 支持 OpenAI 兼容 API，灵活切换模型提供商

## 功能场景

| 场景 | 描述 |
|------|------|
| 文件检索 | 自然语言描述需求，AI 在工作区中定位目标文件 |
| 知识整理 | 自动发现混乱目录，提出归档建议并执行整理 |
| 项目理解 | 基于探索历史回答"这个目录/文件是做什么的" |
| 内容摘要 | 读取文件内容并提炼关键信息 |
| 联网搜索 | 结合本地文件与实时网络信息进行综合回答 |

## 技术架构

```
用户输入 → 状态机 → LLM API → 工具执行 → 持续循环
```

**核心模块：**
- `Agent.js` — 状态机与思考循环核心
- `tools.js` — 文件操作工具集（ls / read / copy / mkdir / create）
- `prompt.js` — 对话历史管理与上下文压缩
- `api/client.js` — OpenAI 兼容 API 流式调用
- `io/terminal.js` — 终端彩色 UI 与分块展示

---

## 快速开始

```bash
# 安装依赖
npm install

# 首次运行（自动引导配置 API 密钥、模型、工作区）
npm start

# 日常启动
npm start
```

**交互方式：**
- ENTER — 打断当前思考，输入指令
- 指令 + ENTER — 发送消息
- exit — 退出程序

## 产品愿景

D 盘、E 盘里堆积的论文、笔记、项目代码、设计素材——这些数据资产长期处于沉睡状态。

CogitoAgent 致力于将它们激活：通过持续探索与智能记忆，让每一个文件都能被精准定位、理解和复用，真正实现**"文件即知识"**。
