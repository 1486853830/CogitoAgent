# 人物视频素材

请将以下三个视频文件放入此目录：

| 文件名 | 状态 | 说明 |
|--------|------|------|
| `idle.mp4` | 待机 | AI 等待用户输入时播放 |
| `thinking.mp4` | 思考 | AI 正在处理请求时播放 |
| `speaking.mp4` | 说话 | AI 正在输出回复时播放 |

## 视频要求
- 格式：MP4（H.264 编码）
- 分辨率：建议 280x560 或等比例
- 背景：建议纯色背景（便于后续抠像）
- 时长：建议 3-5 秒循环

## 视频素材来源
- 自己录制
- AI 生成（如 HeyGen、D-ID 等）
- 免费素材网站
