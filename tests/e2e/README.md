# E2E 测试

本目录包含 CogitoAgent 的端到端测试，覆盖 WebSocket 通信和 Agent 完整流程。

## 测试文件

| 文件 | 说明 |
|------|------|
| `websocket.test.js` | WebSocket 通信测试 |
| `agent-flow.test.js` | Agent 完整流程测试 |

## 运行测试

```bash
# 运行所有 E2E 测试
npm run test:e2e

# 监听模式（文件变化时自动重新运行）
npm run test:e2e:watch

# 运行所有测试（包括单元测试）
npm test
```

## WebSocket 测试

测试 WebSocket 服务器和客户端之间的通信：

- 连接建立和关闭
- Ping/Pong 心跳机制
- 消息发送和接收
- 多并发连接处理
- 错误处理

## Agent 流程测试

测试 Agent 的核心功能：

- **初始化**：配置加载、人设加载、工具注册
- **思考循环**：定时触发、上下文构建
- **工具执行**：工具调用解析、参数验证、错误处理
- **状态机**：状态转换、用户交互
- **会话管理**：创建、切换、删除、上下文压缩
- **记忆系统**：添加、搜索
- **任务管理**：创建、完成、分解
- **API 集成**：请求构建、错误处理
- **命令处理**：命令解析、参数提取

## 测试端口

WebSocket 测试使用端口 `19527`，确保该端口未被占用。

## 超时配置

E2E 测试默认超时时间为 60 秒，可在 `jest.config.mjs` 中修改 `testTimeout`。
